## 🌟 Overview

**UniGrade Pro** is a responsive web application designed to help university students take full control of their academic trajectory. From dynamic SGPA and CGPA modeling to attendance percentage predictions and required exam marks calculation, UniGrade Pro provides instant, reliable calculations in an intuitive, modern interface.

🔗 **Try the Live App:** [https://unigrade-pro.vercel.app](https://unigrade-pro.vercel.app)

---

## ✨ Key Features

- **📊 SGPA / GPA Calculator**: Weighted credit calculation with custom grading scales and semester breakdowns.
- **📈 Cumulative CGPA Planner**: Multi-semester aggregate tracking to project target graduation honors and cutoffs.
- **🎯 Attendance Target Tracker**: Calculates current attendance percentage and tells students exactly how many upcoming classes they can safely skip or must attend to reach 75% or 80% criteria.
- **🔮 Exam Mark Predictor**: Determine minimum final exam scores required to secure target letter grades based on internal continuous assessments.
- **📑 PDF Report Generation**: One-click client-side export to generate clean academic summary PDFs (powered by `jspdf` & `html2canvas`).
- **🌓 Adaptive Theme**: Smooth dark and light mode toggle with system preference synchronization via `next-themes`.
- **⚡ SEO & Rich Previews**: Built-in JSON-LD structured schema (`SoftwareApplication`), Open Graph tags, and dynamic sitemaps.

## 🚀 Getting Started

### Prerequisites
- Node.js 18.17+ or later
- npm or yarn or pnpm

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/bariiqmalik/unigrade-pro.git
   cd unigrade-pro
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Navigate to [http://localhost:3000](http://localhost:3000).
